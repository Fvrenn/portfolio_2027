# portfolio_2027

Portfolio de Timothé — développeur web, créateur de produits. Site vitrine en React 19, Vite 7, TypeScript et Tailwind 4, animé avec GSAP et Lenis, sur le thème de la randonnée en montagne.

## Lancer le projet

```bash
npm install
npm run dev      # serveur de développement
npm run build    # vérification TypeScript + build de production
```

## Documentation

- `GUIDE-CODE-PROPRE.md` : règles de code.
- `STRATEGIE-PORTFOLIO.md` : objectifs du portfolio et public visé.
